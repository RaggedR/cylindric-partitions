# Research

The primary mathematical research repository for algebraic combinatorics work on Warnaar's Conjecture 2.7 — proving positivity of Q_{n,c}(q) polynomials from cylindric partition generating functions (A₂ Andrews-Gordon identities). Includes a full computation pipeline, LaTeX notes (22+ pages), an ArXiv RAG system (62 papers), and LR puzzle triangle tools.

## Tech Stack
- Python 3 / SageMath (conda)
- LaTeX (pdflatex)
- Python (OpenAI embeddings + ChromaDB for RAG)

## Setup
```bash
conda activate sage
python compute.py
```
